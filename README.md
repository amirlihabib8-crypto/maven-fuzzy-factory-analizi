# Maven Fuzzy Factory - E-ticarət Analizi

Bu repozitoriyada Python və Pandas kitabxanasından istifadə edərək real e-ticarət məlumatları (`orders.csv`) əsasında ilkin data analizi həyata keçirilmişdir.

## Layihənin əsas məqsədləri və icra olunanlar:
- **Gəlir və Mənfəət Hesablaması:** Ümumi satış qiyməti ilə maya dəyəri (COGS) fərqi hesablanaraq xalis qazanc tapılmışdır.
- **Səbət Analizi:** Sifariş başına düşən orta məhsul sayı (`items_purchased`) təyin edilmişdir.
- **Məhsul Qruplaşdırması:** `groupby` əməliyyatları vasitəsilə ən çox sifariş olunan məhsullar müəyyənləşdirilmişdir.

## İstifadə olunan alətlər:
- Python
- Pandas
